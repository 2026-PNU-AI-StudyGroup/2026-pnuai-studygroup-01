# PMS UI 디자인 기준

`pms-ui-concept-capstone-studio.png`은 정보 구조와 활자 리듬을 검토한 참고 시안이다. 사이트 정체성은 시안의 테마보다 사용자 피드백과 `STYLESEED.md`의 학과 전체 프로젝트 관리 원칙을 우선한다.

`pms-ui-concept-editorial.png`은 공모전 카탈로그 인상이 강해 폐기한 탐색안이며 구현 기준으로 사용하지 않는다.

## 방향

- 전형적인 관리자 대시보드 대신 콘텐츠 중심의 편집형 화면 구성
- 캡스톤 디자인은 주요 기본 프로그램으로 콘텐츠에서 드러내되 사이트 전체를 캡스톤 전용으로 테마화하지 않음
- 해커톤, 대회, 교육 및 기타 학과 프로젝트를 동일한 프로그램→주제→팀→진행→보고서 구조로 수용
- 데스크톱은 슬림한 상단 내비게이션, 모바일은 하단 내비게이션 사용
- 정보마다 카드를 만들지 않고 여백과 얇은 구분선으로 계층 표현
- 페이지 canvas와 주요 surface는 white `#FFFFFF` 사용
- cool gray는 입력, 선택, 보조 섹션의 제한된 tonal surface에만 사용
- Cobalt `#2F5BEA`는 상호작용과 위치를, Campus Gold `#D58A00`은 한 화면 한 곳의 따뜻한 초점 장식만 담당
- success, warning, danger 색은 실제 의미를 가진 상태와 피드백에만 사용
- 시안에 포함된 다색 카테고리 아이콘 타일은 구현하지 않으며, 아이콘과 장식은 Cobalt와 gray로 제한
- 한 화면의 focal point는 제목 또는 하나의 primary action 한 곳으로 제한
- 자체 호스팅 Pretendard Variable과 140ms Snap 상호작용 사용
- 그림자와 부유 카드를 사용하지 않고 divider, border, whitespace로 구조화
- 홍보성 카피, 전시·공모전 카탈로그 연출, 01/02 순번 장치를 사용하지 않음
- 예술성은 과장된 장식 대신 활자 크기, 정렬, 여백, 구분선의 리듬으로 표현
- 최소 44px 상호작용 영역과 명시적인 키보드 포커스 제공

## 적용 화면

- 랜딩 및 로그인
- 역할별 프로젝트 현황
- 학생 주제 탐색 및 지원
- 교수 주제 관리 및 지원 검토
- 관리자 학기 관리
- 프로젝트 공간
- 공통 빈 상태, 404, 오류 복구 상태

## 주제 탐색 통합안

- `pms-topics-program-filter-desktop.png`과 `pms-topics-program-filter-mobile.png`은 별도 프로그램 목록을 주제 탐색 상단의 선택형 태그 필터로 흡수한 구현 기준 시안이다.
- 프로그램은 카드나 독립 콘텐츠 섹션이 아니다. `전체`와 현재 공개 프로그램을 같은 높이의 플랫 태그로 제공하고, 선택 즉시 같은 화면의 주제 목록을 좁힌다.
- 주제 행은 긴 설명을 임의로 잘라내지 않으며 모집·수행·제출 기간 전체, 요구 기술과 역할 조건을 한 흐름으로 읽게 한다.
- 학생에게는 같은 화면 후반에 마감·거절을 포함한 전체 지원 이력을 제공한다.
- 기존 `/programs` 화면과 카드형 프로그램 탐색은 폐기하고 `/topics`로 통합한다.

## 지난 프로젝트 아카이브

- `pms-project-archive-desktop.png`과 `pms-project-archive-mobile.png`은 부산대 학과 프로젝트 관리 웹서비스에서 캡스톤을 중심으로 종료된 선배 프로젝트와 결과물을 참고하는 아카이브 시안이다.
- 승인된 시안의 핵심은 별도 아카이브 화면이 아니라 `/topics` 하나에서 `진행 중 프로젝트`와 `종료된 프로젝트`를 전환하는 프로젝트 탐색 구조다.
- 데스크톱은 기존 슬림 상단 전역 내비게이션을 유지하면서 좌측 레일에서 진행 중·종료됨을 전환하고 실제 `내 프로젝트`, 학생의 `팀원 모집` 경로로 이동한다. 모바일에서는 레일을 숨기고 상단 2분할 전환을 사용한다.
- 종료됨 화면은 시안의 학년도 태그, 검색·프로그램 분류 필터, 표형 평면 목록과 하단 페이지 이동을 사용한다. 진행 중 화면은 동일한 콘텐츠 폭 안에서 프로그램 태그, 공개 주제와 학생의 전체 지원 이력을 보존한다.
- 시안의 가짜 관심 기능과 다른 학과 필터는 구현하지 않는다. 전체 설명과 실제 공개 결과물은 목록 높이를 늘리는 인라인 확장 대신 `/topics/archive/[projectId]` 상세 화면에서 확인한다.
- 아카이브는 기술적 파일 백업·복원 화면이 아니다. 종료된 프로젝트를 학년도, 주제, 팀, 교수, 기술, 결과물로 찾아보는 학습·참고 공간이다.
