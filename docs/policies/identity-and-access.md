# 계정과 접근 권한 정책

## 가입과 세션

- Google 계정의 이메일이 검증되었고 `@pusan.ac.kr` 도메인이어야 신규 사용자를 만들 수 있다.
- 이메일은 앞뒤 공백을 제거하고 소문자로 저장한다.
- 신규 계정은 먼저 학생으로 만들어지며 학생 온보딩이 필요하다.
- 세션 생성 직전에 교수 허용 목록을 다시 확인한다. 관리자 계정을 제외하고 허용 목록에 있으면 교수로, 없으면 학생으로 맞춘다.
- `DISABLED`와 `WITHDRAWN` 계정은 새 세션을 만들 수 없고 기존 세션도 로그인 사용자로 인정하지 않는다.
- 교수로 승격할 때 학생 온보딩 요구를 해제한다.

## 인증 환경

- 운영 환경의 인증 기준 URL은 HTTPS여야 하고 인증 비밀키는 공개 예시가 아닌 32자 이상의 값이어야 한다.
- 개발용 목 인증을 사용하지 않으면 Google OAuth 클라이언트 ID와 비밀키가 필수다.
- 개발용 목 인증은 개발 환경의 로컬 호스트, 또는 명시적으로 활성화하고 허용 목록에 넣은 호스트의 동일 출처 요청에서만 동작한다.
- 목 인증은 시드에 있는 고정 역할 계정이 현재 활성 상태일 때만 세션을 만든다.

## 역할

| 역할 | 기본 범위 |
| --- | --- |
| 학생 | 프로젝트 지원·제안, 학생 팀, 소속 실행 팀 활동 |
| 교수 | 담당 프로젝트·팀 운영, 지원 검토, 보고서 검토, 공지 작성 |
| 관리자 | 전체 운영 설정과 예외 없는 전역 관리 |

- 운영 기능은 온보딩을 완료한 학생만 사용할 수 있다.
- 교수 허용 목록과 사용자 활성 상태는 관리자만 관리한다.
- 교수 권한 회수는 해당 교수가 담당하는 종료 전 프로젝트나 활성 실행 팀이 없을 때만 허용한다.
- 교수 권한 회수 후 학생 필수 가입 정보가 없으면 다음 로그인부터 학생 온보딩을 다시 요구한다. 기존 학생 온보딩을 완료했던 사용자는 저장된 정보를 유지한다.
- 사용자 비활성화 시 현재 관리자 본인과 마지막 활성 관리자는 대상이 될 수 없다.
- 담당 프로젝트가 있는 교수는 비활성화할 수 없다.
- 비활성화가 성공하면 해당 사용자의 세션을 모두 삭제한다.

## 계정 탈퇴

- 탈퇴는 사용자 행을 삭제하지 않고 계정 상태를 `WITHDRAWN`으로 바꾸며 탈퇴 시각을 기록한다.
- 탈퇴 즉시 모든 세션을 삭제한다. 완료 프로젝트, 작성물, 평가와 감사 기록의 사용자 관계는 보존한다.
- 마지막 활성 관리자와 종료 전 담당 프로젝트가 있는 교수는 탈퇴할 수 없다.
- 학생 사전 팀장과 종료 전 프로젝트 팀장은 다른 현재 팀원에게 팀장을 이전한 뒤 탈퇴할 수 있다.
- 학생의 사전 팀 멤버십은 제거하고 구성 버전을 증가시킨다. 종료 전 프로젝트 멤버십은 `ACCOUNT_WITHDRAWN` 사유로 종료한다.
- 대기 중인 프로젝트 지원·학생 팀 모집 지원·초대·프로젝트 승인 요청은 철회 또는 취소한다.

## 학생 온보딩

- 이름은 공백을 정리한 2~50자, 학과는 2~100자다.
- 학번은 공백과 하이픈을 제거한 숫자 6~12자리이며 전체 사용자에서 고유하다.
- 학년은 1~6의 정수다.
- 전화번호는 필수이며 공백·괄호·하이픈을 제거한 뒤 선택적 `+`와 숫자 8~15자리여야 한다.
- 연락 이메일도 필수이며 이메일 형식이고 254자 이하다.
- 온보딩은 학생 한 명당 필요한 상태에서 한 번만 완료한다.
- 온보딩 후 학생은 본인의 학과, 학번, 학년, 전화번호, 연락 이메일을 같은 형식으로 다시 수정할 수 있다.
- 전화번호의 단일 저장 원본은 `User.phoneNumber`다. 온보딩과 계정 연락처 수정은 같은 값을 읽고 갱신한다.

## 학생 연락처와 공개 범위

- 학생 본인만 전화번호, 카카오톡, GitHub, Instagram 정보를 수정한다.
- 전화번호는 온보딩의 필수 형식과 동일하게 검사하고 `User.phoneNumber` 한 곳에만 저장한다. 별도 연락처 프로필에 전화번호를 중복 저장하지 않는다.
- 나머지 항목은 비어 있거나 공백·한글이 없는 출력 가능한 ASCII 문자열이며 각각 200자 이하다.
- 학생 팀 연락처는 같은 학생 팀의 구성원에게 보인다.
- 실행 팀 연락처와 학사 정보는 해당 실행 팀의 팀원·담당교수·조교·관리자에게 보인다.
- 화면별 전화번호 노출 여부는 접근 권한으로 제어하며 별도 공개용 전화번호 값을 만들지 않는다.

## 프로필 사진

- 로그인 사용자는 본인 사진만 등록·교체·삭제할 수 있다.
- JPEG, PNG, WebP만 허용하고 최대 크기는 5MiB다.
- 파일명은 1~255자, SHA-256은 64자리 16진수여야 한다.
- 업로드 완료 시 MIME 유형, 크기, SHA-256과 파일 매직 바이트를 다시 확인한다.
- 업로드 URL은 15분 동안 유효하다. 한 사용자에게 동시에 남아 있을 수 있는 대기 업로드는 3개다.
- 완료 요청은 같은 업로드에 대해 반복되어도 이미 완료된 상태를 성공으로 반환한다.
- 사진은 본인·관리자 또는 같은 실행 팀의 팀원·담당교수·조교 관계가 있는 사용자만 조회한다.
